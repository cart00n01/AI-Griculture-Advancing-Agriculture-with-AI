# AI-Griculture: Advancing Agriculture with AI

Welcome to **AI-Griculture**, an open-source project dedicated to revolutionizing agriculture using the power of Artificial Intelligence (AI). This repository aims to provide innovative AI-driven solutions for modern agricultural challenges, empowering farmers, researchers, and agri-tech enthusiasts worldwide.

## 🌱 Project Overview

AI-Griculture leverages state-of-the-art AI and machine learning techniques to:

- Monitor crop health using computer vision
- Predict crop yields based on environmental and sensor data
- Detect pests and diseases automatically
- Optimize irrigation and fertilization schedules
- Provide actionable insights and recommendations

Whether you're a farmer looking to improve your yield, a researcher exploring agri-tech, or a developer passionate about AI for social good, this repository is for you!

## 🚀 Features

- **Crop Health Monitoring:** Image-based plant disease detection and health assessment.
- **Yield Prediction:** Machine learning models to forecast crop yields.
- **Smart Irrigation:** AI-powered scheduling for efficient water usage.
- **Pest & Disease Detection:** Early alerts from sensor and image data.
- **Data Dashboard:** Visual analytics for easy decision making.


## 🛠️ Tech Stack

- Python, TensorFlow / PyTorch
- OpenCV for computer vision
- Scikit-learn for ML models
- Flask / FastAPI backend
- React / Streamlit dashboard
- Docker for containerization

## ⚡ Getting Started

1. **Clone the repo**
    ```bash
    git clone https://github.com/cart00n01/AI-Griculture-Advancing-Agriculture-with-AI.git
    cd AI-Griculture-Advancing-Agriculture-with-AI
    ```

2. **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3. **Run sample notebook**
    - Explore the `notebooks/` directory for demos and experiments.

4. **Start the web dashboard**
    ```bash
    cd webapp
    # Follow instructions in webapp/README.md
    ```

# How to run on your local host?

-Download PyCharm

-Create new environment using command --> conda create -n env_name python==3.7.0

-Activate environment using command --> conda activate env_name

-Install requirements by typing (cd ProjectFolder) --> pip install -r requirements.txt

-Now run app.py by writing command --> python app.py
